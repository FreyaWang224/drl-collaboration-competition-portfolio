# Collaboration and Competition Portfolio

Status: requirements audit and multi-agent RL study. No environment downloaded, training run, or evaluation result yet.

This is an independent Project 3 repository. Baseline: independent DDPG; MADDPG is a possible later comparison, selected only after diagnosing real experiments.

Udacity requires its supplied Tennis environment, Python 3/PyTorch training code, successful weights, root README and Report. Each episode score is the maximum of the two undiscounted agent returns; solved means a mean of at least 0.5 across 100 consecutive episodes.

The course describes 8 observation variables per agent and 2 continuous actions. Runtime observation dimension and stacking remain unverified. Official legacy Python package is unityagents 0.4.0; Unity Editor build version is not established. Do not substitute modern ML-Agents Tennis.

Sources: [course](https://learn-udacity.top/udrl597102/Deep%20Reinforcement%20Learning%20Nanodegree%20v5.0.0/index.html), [official project](https://github.com/udacity/deep-reinforcement-learning/tree/master/p3_collab-compet), [API version](https://github.com/udacity/deep-reinforcement-learning/blob/master/python/setup.py).
